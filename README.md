## 📌 Giới thiệu dự án

Trang web **Personal Portfolio** cá nhân được xây dựng với mục tiêu giới thiệu bản thân, các kỹ năng lập trình web, các dự án thực hành và kênh liên hệ. Trang web được thiết kế theo chuẩn responsive, giao diện hiện đại và tối ưu hóa trải nghiệm người dùng.

### ✨ Các tính năng nổi bật:
- 📱 **Responsive Design**: Tương thích tốt trên cả Mobile, Tablet và Desktop.
- 🌓 **Dark / Light Mode**: Hỗ trợ chuyển đổi giao diện Sáng / Tối linh hoạt và lưu trạng thái vào LocalStorage.
- ⌨️ **Typing Animation**: Hiệu ứng chữ gõ tự động sinh động tại phần Hero.
- 🧭 **ScrollSpy & Smooth Navigation**: Cuộn trang mượt mà và tự động highlight mục menu đang xem.
- 📬 **Interactive Contact Form**: Form liên hệ có kiểm tra tính hợp lệ và thông báo phản hồi trực quan.

## 🌐 Hướng dẫn nộp bài bằng GitHub Pages (github.io)

Chi tiết xem tại hướng dẫn đính kèm hoặc thực hiện các bước:
1. `git init`
2. `git add .`
3. `git commit -m "feat: complete welcome to my portfolio lab"`
4. `git branch -M main`
5. Tạo repository trên GitHub và kết nối remote: `git remote add origin https://github.com/<username>/<repo>.git`
6. `git push -u origin main`
7. Vào **Settings** -> **Pages** -> Tại mục **Branch** chọn `main` / `root` -> **Save**.
8. Lấy link dạng `https://<username>.github.io/<repo>/` để gửi giáo viên.
